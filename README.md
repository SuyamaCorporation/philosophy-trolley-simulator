# Philosophy Trolley Problem Simulator

**Category:** Ethics / Game

A branching ethical dilemma game featuring 12 trolley problem variations (classic, footbridge, loop, transplant, ticking bomb, scapegoat, and more). After completing a shuffled set of 9 scenarios, your choices are analyzed against utilitarian, deontological, and virtue ethics frameworks. Inconsistencies between decisions are surfaced to illuminate moral intuition patterns.
